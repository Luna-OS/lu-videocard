# Lu Videocard 1.0.0

The first Lu Videocard: your HDMI capture card in a window, in the Luna-OS Moon look, with an
axolotl as its icon.

- Finds the capture card by itself (not the webcam) and pairs it with its own sound input.
- Picture at up to 1080p · 60 fps (or 1440p / 4K · 30 fps, if the card has it), shown without
  scaling or delay.
- Clean sound: stereo, no echo cancellation, no noise suppression, no automatic volume; volume,
  mute, a live level meter and a choice of speaker.
- Fullscreen (F) and stream mode (C): nothing but the picture – no title bar, no buttons, no
  borders – for sharing on Discord. In stream mode the window keeps the picture's 16:9 shape.
- Fit, fill or stretch the picture; screenshots in full resolution (Ctrl+S).
- Comes back by itself when the card is unplugged and plugged back in; says so when another
  program is using it.
- Updates itself from GitHub releases.
